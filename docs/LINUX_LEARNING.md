# Linux concepts in this project

A reading list that follows the code. `man` pages are installed on your system;
`man 2 open` means section 2 (system calls).

| Concept | Where in the code | Try this |
|---|---|---|
| **Everything is one tree.** There are no `C:`/`D:` drives; other disks are *mounted* into folders. | `defaultRoots()` returns just `/` | `findmnt` · `lsblk` |
| **Virtual filesystems.** `/proc`, `/sys` and `/dev` are generated by the kernel and aren't on disk. Crawling them is pointless, and sometimes infinite. | `LinuxMounts.cpp`, `defaultExcludes()` | `cat /proc/self/mountinfo` · `ls /proc/$$` |
| **System calls.** Programs ask the kernel for everything through syscalls. | `LinuxScanner.cpp` | `strace -c ./build/release/fe-cli --root ~` |
| **File descriptors.** `open()` returns a small integer that refers to an open file or directory. | `open(..., O_DIRECTORY)`, `fstatat(fd, ...)` | `ls -l /proc/$$/fd` |
| **Inodes and `stat`.** Names live in directories; size, times and permissions live in the inode. | `fstatat` in the scanner | `stat ~/.bashrc` · `ls -i` |
| **Directory entries.** `readdir` wraps the `getdents64` syscall. `d_type` gives the type without a `stat`. | the `readdir` loop | `man 3 readdir` |
| **Symlinks.** We never follow them, to avoid loops and double counting. | `O_NOFOLLOW`, `AT_SYMLINK_NOFOLLOW` | `ln -s / ~/loop` and see that we don't loop |
| **Permissions.** Normal users can't read some folders. | `progress.errors` | `ls -ld /root` · run with `sudo` |
| **Threads.** | `Search.cpp`, `MainWindow::startIndexing` | `htop`, press `H` to show threads |
| **Change notification.** inotify watches one directory at a time; fanotify can watch a whole filesystem. | `LinuxWatcher.cpp` (M3) | `man 7 inotify` · `man 7 fanotify` · `cat /proc/sys/fs/inotify/max_user_watches` |
| **XDG directories.** Where apps keep config and cache. | M4 | `ls ~/.config ~/.cache` |
| **Display server.** GLFW talks to X11 (or Wayland); OpenGL draws the pixels. | `app/main.cpp` | `echo $XDG_SESSION_TYPE` |

Useful tools: `gdb`, `strace`, `ltrace`, `perf`, `valgrind --tool=massif` (memory), `htop`, `lsof`.
